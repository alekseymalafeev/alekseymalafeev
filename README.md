## Как я работаю

### 🔎 Анализирую глубже очевидного

В SEO недостаточно просто увидеть изменение трафика, позиций или количества страниц в индексе.

Мне интересно понять **почему это произошло** и какие менее очевидные факторы могли на это повлиять.

Использую критическое мышление, чтобы:

* находить взаимосвязи между разными SEO-сигналами;
* замечать аномалии и несоответствия в данных;
* ставить под сомнение очевидные объяснения;
* превращать наблюдение в проверяемую гипотезу;
* находить проблемы, которые не видны при стандартном аудите.

**Не только смотрю на данные — пытаюсь понять, что за ними стоит.**

---

### 💡 Ищу нестандартные решения

Не каждую SEO-проблему можно решить готовым инструментом или стандартным чек-листом.

Иногда приходится искать обходной путь: комбинировать данные из разных источников, писать собственный парсер, сравнивать поведение сайта для разных User-Agent или строить мониторинг там, где его изначально не было.

Поэтому в работе мне помогает **творческий подход к решению технических задач**:

> если готового способа проверить гипотезу нет — можно придумать свой.

---

### ⚙️ Автоматизирую то, что имеет смысл автоматизировать

Если задача повторяется десятки или сотни раз, ручная работа постепенно превращается в источник ошибок.

Поэтому я использую Python и API для:

* сбора и обработки SEO-данных;
* технических аудитов;
* парсинга больших объёмов URL;
* мониторинга изменений;
* поиска аномалий;
* регулярных проверок;
* объединения данных из разных источников.

Мой принцип:

**задача → гипотеза → данные → проверка → автоматизация → результат.**
