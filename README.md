## SEO engineering — как я это вижу

**SEO engineering** — это не «уметь кодить как разработчик». Это умение:

1. **Переводить SEO-гипотезу в проверяемый процесс**  
   Например: «не индексируется» → снять URL из sitemap → сверить status/meta robots → увидеть расхождение у бота и у пользователя.

2. **Снимать рутину с масштабом**  
   Один раз описать шаг, который иначе делается руками сотни раз: парсинг sitemap index, периодический контроль meta robots, сверка выдачи боту.

3. **Держать фокус на сигналах поиска**  
   HTTP-код, `meta robots`, User-Agent бота, структура sitemap — то, от чего зависит, попадёт ли страница в индекс и как её увидят Googlebot / YandexBot.

Скрипт здесь — ускоритель аудита и мониторинга, а не продукт сам по себе.

## Репозитории

### [links-from-sitemap](https://github.com/alekseymalafeev/links-from-sitemap)
Скачивает все URL из sitemap, включая вложенные XML из sitemap index. Поддержка `.gz` / Brotli, вывод в Excel или CSV.

*Зачем SEO:* быстро получить полный список URL сайта «как его отдаёт sitemap» — для сверки с индексом, краулом или выгрузкой из CMS.

### [meta-robots-monitor](https://github.com/alekseymalafeev/meta-robots-monitor)
Периодически проверяет страницу: HTTP-код и содержимое `meta robots` для выбранного User-Agent (Client / Googlebot / YandexBot и др.).

*Зачем SEO:* поймать ночные/деплой-изменения индексации, когда страница внезапно становится `noindex` или отдаёт другой код боту.
